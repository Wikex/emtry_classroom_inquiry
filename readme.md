# 空闲教室查询助手

这是一个Tampermonkey 用户脚本，在“空闲教室查询”页面自动提取课表数据，并通过高级条件筛选功能，快速找到适合长时间连续自习的空闲教室。

## ✨ 核心功能

- **一键浮窗唤起**：在页面右下角自动添加“🏫 查空教室”悬浮按钮，随时点击呼出高级查询面板。
- **自动数据提取**：自动读取当前教务系统页面上的教室课表概况，无需手动输入或刷新页面抓包。
- **高级条件筛选**：
  - 提供 5 个时间段选择（上午1-2节、上午3-4节、下午1-2节、下午3-4节、晚上）。
  - 根据你想要开始自习的时间段，自动筛选并展示自选定时间起**连续空闲**的教室。
- **可视化结果展示**：
  - 统计可用教室总数。
  - 列表展示教室名称。
  - 以直观的色块（🟧 有课 / ⬜ 没课）展示该教室当天的全天课表概览。
  - 清晰列出满足条件的连续可用自习时间段。

## 🚀 安装指南

### 前置要求
你需要在浏览器中安装用户脚本管理器扩展，推荐使用：
- [Tampermonkey (篡改猴)](https://www.tampermonkey.net/)（支持 Chrome, Edge, Firefox, Safari 等大多数现代浏览器）

### 安装脚本
1. 确保已安装并启用 Tampermonkey 扩展。
2. 将项目中的 `classroom-finder.user.js` 脚本内容复制。
3. 点击浏览器扩展栏的 Tampermonkey 图标，选择 **“添加新脚本”**。
4. 将原本编辑器里的内容清空，粘贴刚才复制的代码。
5. 点击 **“文件” -> “保存”**（或使用快捷键 `Ctrl + S`）。

## 💡 使用说明

1. 登录https://jwxt.tjut.edu.cn/jwmobile/index#/pkApp/kxjscx/index
2. 导航至 **“空闲教室查询”** 相关页面，并点击【查询】按钮加载出带有课表小方块的教室数据列表，加载完整页面。
3. 点击页面右下角的悬浮按钮 **“🏫 查空教室”**。
4. 在弹出的查询面板中，确认系统是否已成功提取当前页面的数据（可点击“重新提取”刷新数据）。
5. 选择你期望开始自习的时间段（如点击“3”代表下午1-2节）。
6. 点击 **“查询符合条件的教室”**，系统会在下方列表展示所有满足条件的教室及其可用时段情况。

## ⚙️ 脚本原理

脚本使用原生 JavaScript 编写，通过注入隔离的 Shadow DOM 构建干净美观的 UI，防止与教务系统原有样式冲突。数据提取过程直接解析 DOM 中的类名标识（如 `.tableLine___2zgYJ`、`.usedRoom___3UEA9` 等），保证数据同步与直观展示。
